# Código de Conduta

Este grupo segue o espírito do AWS Student Builder Group e da comunidade open source:

1. **Seja respeitoso** — toda pessoa é bem-vinda, independente de curso, nível ou background.
2. **Aprenda junto** — dúvida não é vergonha; gatekeeping não é bem-vindo.
3. **Construa com segurança** — não compartilhe dados sensíveis nem credenciais.
4. **Represente o campus** — eventos e posts oficiais seguem as diretrizes do programa AWS SBG.
5. **Reportar problemas** — fale com o Group Leader ou com o time Moderators.

Violações podem resultar em remoção de issues/PRs e, em casos graves, remoção da organização.

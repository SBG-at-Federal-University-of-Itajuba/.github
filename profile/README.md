## Missão

O **AWS Student Builder Group** junta estudantes para aprender computação em nuvem, construir projetos reais e se conectar com outros builders no mundo todo.

Na UNIFEI, a gente coloca isso em prática de dois jeitos:

1. **Aprender AWS juntos** — workshops, labs e projetos hands-on
2. **Fortalecer a comunidade** — no campus e no [AWS Builder Center](https://builder.aws.com)

> Todo estudante tem lugar aqui. A gente aprende melhor em grupo do que sozinho.

## Como começar

1. Explore os repositórios públicos desta organização
2. Entre no [AWS Builder Center](https://builder.aws.com) com o mesmo e-mail do seu AWS Builder ID
3. Acompanhe os eventos oficiais do grupo no Meetup (canal oficial de eventos do programa)
4. Quer ajudar a organizar? Fale com o Group Leader / Core Team

Não sabe por onde começar na AWS?

→ [AWS Skill Builder](https://skillbuilder.aws) · [AWS Educate](https://aws.amazon.com/education/awseducate/) · [Builder Center](https://builder.aws.com)

## Estrutura do grupo (campus)

Baseado no *AWS Student Builder Group Leader Handbook* (2026):

| Papel | Responsabilidade |
|-------|------------------|
| **Group Leader** | Lidera o grupo no campus, eventos e comunidade |
| **Core Team** (2–5) | Ajuda a rodar o grupo (eventos, marketing, tech…) |

## Governança deste GitHub

Queremos a org **aberta para leitura** e **fechada para escrita acidental**.

| Quem | Pode |
|------|------|
| Público | Ver e clonar repositórios **públicos** |
| Membros da org | Ver o que for liberado; **sem** criar repo nem push por padrão |
| Time **Moderators** | Criar repos, push, settings, convidar e moderar |
| Org owners | Administração completa da organização |

Contribuições externas: abra um **Pull Request**. Só Moderators fazem merge.

Detalhes: veja [`CONTRIBUTING.md`](../CONTRIBUTING.md) e [`CODE_OF_CONDUCT.md`](../CODE_OF_CONDUCT.md) neste repositório `.github`.
